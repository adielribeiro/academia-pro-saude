# Proposta comercial — Site Academia Pro Saúde Fitness

## Objetivo

Criar um site institucional moderno para a Academia Pro Saúde Fitness, com foco em:

- Apresentar a academia de forma profissional.
- Facilitar contato pelo WhatsApp.
- Mostrar modalidades, horários e localização.
- Melhorar a credibilidade da marca no Instagram, Facebook e Google.
- Ter uma página pronta para anúncios e divulgação em redes sociais.

## O que o site entrega

### 1. Página inicial forte

Hero visual com chamada direta, botão de WhatsApp, endereço e horário de funcionamento.

### 2. Sobre nós

Texto institucional para apresentar a academia como uma opção próxima, confiável e focada em saúde.

### 3. Modalidades

Cards com os principais serviços:

- Musculação
- Condicionamento físico
- Emagrecimento
- Ganho de massa

### 4. Horários

Bloco claro com horário de funcionamento para evitar dúvidas dos alunos.

### 5. Contato com WhatsApp

Formulário simples que abre uma mensagem pronta no WhatsApp da academia.

### 6. Mapa

Mapa integrado para facilitar a localização.

### 7. Galeria com redes sociais

Uso inicial das imagens das redes sociais para valorizar a presença digital já existente.

## Argumentos para venda

- Hoje muitos alunos pesquisam no Google antes de visitar uma academia.
- Um site passa mais confiança do que depender apenas do Instagram.
- O botão de WhatsApp reduz atrito e aumenta conversões.
- O site pode ser usado em anúncios pagos.
- A academia ganha uma apresentação profissional para novos alunos.
- O projeto pode evoluir para página de planos, landing page de matrícula ou integração com campanhas.

## Tecnologias utilizadas

- React
- Vite
- Material UI
- Vercel
- GitHub

## Sugestão de entrega ao cliente

Entregar como um pacote inicial:

1. Site institucional responsivo.
2. Publicação na Vercel.
3. Configuração de domínio.
4. Ajustes de textos e fotos reais.
5. Botões de WhatsApp e redes sociais.

## Próximos incrementos possíveis

- Página de planos e mensalidades.
- Depoimentos de alunos.
- Página de matrícula.
- Blog com dicas de treino e saúde.
- Integração com Pixel do Meta e Google Analytics.
- Campanhas para captação de leads.
